01

Le principe

Toutes les marques utilisent la même plateforme, mais pas les mêmes fonctions. SellingAtHome active, pour chaque marque, les fonctions prévues dans son contrat. Vous ne pouvez pas les activer vous-même depuis l'espace marque.

Accès aux menus et modules

Une fonction activée fait apparaître un menu, un sous-menu ou un onglet (par exemple Paramètres › Commissionnement). Désactivée, elle disparaît de l'espace marque, et souvent aussi de l'espace conseillère.

Options de fonctionnement

Une option change le comportement d'une fonction existante (commandes de regroupement, réunion en visio, mini-site de réunion…). Elle peut aussi faire apparaître un sous-menu ou une case à cocher.

Une fois une fonction activée, c'est vous qui la paramétrez, comme le reste de votre espace marque.

Vocabulaire

Dans l'espace marque, les conseillères sont appelées vendeurs ou VDI (par exemple « Carte des VDIs »). Cette page parle de conseillères, mais cite les menus exactement comme à l'écran.

02

Pourquoi un menu n'apparaît pas

Vous lisez une page de cette documentation et le menu décrit n'existe pas chez vous ? Voici les causes possibles.

La fonction n'est pas activée pour votre marque.→Demandez à SellingAtHome
Le menu dépend d'une autre fonction : par exemple l'onglet « Cotisations Sociales » n'existe qu'avec le plan de rémunération.→Les deux doivent être actives
Un menu principal ne s'affiche que si au moins un de ses sous-menus est activé (Catalogue, Paramètres, Formulaires, Base de connaissances…).→Normal
La fonction existe en deux versions et s'affiche à un autre endroit selon la vôtre (Retours d'articles : sous-menu de Formulaires ou menu à part).→Cherchez dans l'autre menu
C'est une case à cocher qui manque (bon de préparation, livraison partielle…).→Option de fonctionnement

06

Demander une activation

Adressez votre demande à votre interlocuteur SellingAtHome (bouton Support en bas du menu de l'espace marque). Pour qu'elle soit traitée sans aller-retour :

  1. Nommez la fonction telle qu'elle apparaît dans cette page (par exemple « Commandes de regroupement »).
  2. Précisez la date à laquelle vous voulez l'ouvrir à vos conseillères.
  3. Préparez son paramétrage : une fonction activée mais non paramétrée peut apparaître vide chez les conseillères.
  4. Prévenez votre réseau : un nouveau menu chez les conseillères appelle une explication.
Exemple

Votre marque veut lancer un challenge de rentrée le 1er septembre. Vous demandez l'activation des Challenges mi-août. Dès qu'elle est faite, l'onglet Challenges apparaît dans Paramètres › Configuration générale : vous préparez le challenge, puis Léa, Chloé et Manon le découvrent dans leur menu Suivi d'activité › Challenges.

07

Questions fréquentes

Une conseillère a un menu que je ne vois pas dans l'espace marque.

Certaines fonctions n'existent que côté conseillère (Appli mobile / tablette, Réseau, Mes documents…). Voir Côté espace conseillère.

Une fonction est activée mais rien n'apparaît chez les conseillères.

Elle n'est peut-être pas encore paramétrée (aucun challenge en cours, aucun document publié…), ou elle dépend d'une autre fonction. Pour Mon assistant, chaque conseillère doit aussi l'activer pour elle-même.

Peut-on désactiver une fonction ?

Oui, sur demande à SellingAtHome. Le menu disparaît alors de l'espace marque et, selon la fonction, de l'espace conseillère.

Où trouver la liste de ce qui est activé pour ma marque ?

L'espace marque n'affiche pas cette liste : comparez votre menu avec les tableaux de cette page, ou demandez-la à votre interlocuteur SellingAtHome.
